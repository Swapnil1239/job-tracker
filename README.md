# 🚀 CareerFlow AI - Job Application Tracker & Apply Assistant

**CareerFlow AI** is a modern, high-performance web application designed to help job seekers **apply 5x faster** while keeping full, organized records of all job applications.

---

## ✨ Key Features

### 1. ⚡ "Apply Faster" Toolkit
- **1-Click Master Profile Clipboard**: Store your standard contact info, LinkedIn, portfolio link, summary, and elevator pitch. Copy any snippet with a single click while filling out forms (Workday, Greenhouse, Lever, LinkedIn, etc.).
- **Tailored AI Cover Letter Generator**: Instantly generate customized, highly professional cover letters tuned to specific job descriptions and desired tone (Confident, Enthusiastic, Executive, or Tech-Focused).
- **Cold Recruiter Outreach Writer**: Auto-generate personalized LinkedIn/email outreach messages to recruiters and hiring managers.
- **1-Click Job Web Clipper**: Bookmarklet setup that extracts job title, company name, and application URL directly from active web pages.

### 2. 📋 Interactive Kanban Application Tracker
- **Drag-and-Drop Workflow**: Drag applications effortlessly across 6 stages:
  - 📌 **Wishlist**
  - 📩 **Applied**
  - 🔍 **Screening**
  - 💬 **Interviewing**
  - 🏆 **Offered**
  - ❌ **Rejected**
- **Follow-Up Reminders**: Automatic alerts for applications pending follow-up (e.g. applied > 7 days ago with no update).

### 3. 📊 Analytics & Conversion Insights
- Real-time metrics: Total Applications, Interview Conversion Rate, Offers Received, and Weekly Goal Progress.
- **Visual Funnel Chart**: Status distribution pie chart using Chart.js.
- **Application Velocity Chart**: Track your application submission activity over time.

### 4. 📑 Applications Directory & Management
- Search by company name, position, skills, or status.
- Filter by Work Mode (Remote, Hybrid, Onsite).
- Store full notes, compensation details, recruiter contacts, and interview schedules.
- 1-Click **JSON Backup Export & Import** so you never lose your records.

## 🛠️ How to Run

### Option 1: Live Server (Recommended)
 Run the following command in terminal:
```bash
cd /Users/swapnil/job-application-tracker
python3 -m http.server 8080
```
Then open your browser and navigate to:
👉 `http://localhost:8080`

### Option 2: Open Directly
Double-click `index.html` or open it directly in Google Chrome, Safari, or Microsoft Edge!

## 🔒 Data Privacy
All your application data and profile details are stored **locally in your browser's LocalStorage**. No data is sent to external tracking servers.
